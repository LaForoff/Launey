# Launey

Современная стартовая страница и менеджер рабочих пространств для macOS.
Launey помогает организовать сайты, сервисы и повседневные задачи в удобные пространства, которые всегда доступны из строки меню macOS.
Создавайте отдельные пространства для работы, покупок, развлечений и других сценариев, настраивайте их внешний вид и быстро переходите к нужным сайтам.

> **Предварительная версия.** Launey находится в активной разработке. Интерфейс и отдельные возможности могут изменяться.

---

## Возможности

- Несколько рабочих пространств
- Добавление сайтов и сервисов
- Создание и сортировка папок
- Пользовательские иконки и фоны
- Автоматический поиск иконок
- Выбор поисковой системы
- Импорт и экспорт данных
- Светлая, тёмная и системная темы
- Автоматические обновления через Sparkle
- Нативное приложение для macOS

---

## Установка

1. Откройте раздел **Releases**.
2. Скачайте архив последней версии Launey.
3. Распакуйте архив.
4. Переместите `Launey.app` в папку **«Программы»**.
5. Запустите приложение.

При первом запуске macOS может запросить подтверждение открытия приложения, загруженного из интернета.
