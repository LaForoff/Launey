# Поиск иконок

Выбор иконки открывается на вкладке «Логотипы». Вначале доступен встроенный каталог SVG Logos с сохранёнными исходными цветами и градиентами; Simple Icons используется при отсутствии совпадений. Затем параллельно добавляются варианты Pubrio, DeBounce и AnyLogo по основному домену и определённому домену продукта. Каждая карточка принадлежит одному источнику; изображения не объединяются по содержимому или сходству. URL плитки не меняется. App Store и загрузка своего файла доступны в отдельных вкладках. Вкладка «С сайта» и её API поиска favicon/manifest удалены из веб- и macOS-сервера. Общие загрузка, кэширование и экспорт изображений сохранены.

## Встроенный каталог

SVG Logos (Gil Barbara, распространение через пакет Iconify `@iconify-json/logos`) входит в приложение отдельным локальным JS-модулем. Он загружается один раз при первом поиске. Все исходные пути, заливки и градиенты сохраняются, изображения не сводятся к одному фирменному цвету. Модуль Simple Icons загружается только при отсутствии совпадений в этом каталоге. Поиск в обоих каталогах не обращается к внешним API.

Точное совпадение названия имеет приоритет над префиксом. Внутри бренда сначала идут подходящие для плитки пропорции, затем цветное оформление. Если для одной формы есть цветное оформление, одноцветный вариант этой формы не предлагается. Форма определяется по реальным размерам из набора, а не по суффиксу файла: у JetBrains именно `jetbrains` — цветной квадрат, а `jetbrains-icon` — чёрно-белый квадрат. Градиенты JetBrains и разноцветные части GitLab покрыты регрессионным тестом. Выводится максимум восемь вариантов. Исходные файлы, включая одноцветные варианты, сохраняются без изменений; контраст при отображении описан ниже.

Коллекция не гарантирует актуальность каждого бренда; это поставляемый с приложением снимок версии пакета. Версии и целостность фиксируются package-lock.json. Источники и сведения о правах: [THIRD_PARTY_ICONS.md](THIRD_PARTY_ICONS.md).

Для `gitlab.lanit-tercom.ru` GitLab предлагается сразу, даже с названием плитки «Репозиторий», при пустой или ошибочной выдаче AnyLogo. Ввод полного адреса в строку поиска тоже сохраняет продуктовую подсказку `gitlab`. Родительский домен остаётся дополнительным вариантом. Сначала отображаются встроенные знаки, затем найденные по названию продукты, затем основной домен.

На реальной проверке AnyLogo вернул для gitlab.com SVG с изображением Barclays. Успех HTTP, правильный домен запроса и безопасный SVG не подтверждают идентичность бренда. Встроенные результаты имеют приоритет, название источника доступно во всплывающей подсказке каждого результата. Автоматического применения нет. Это ограничение источника; проверка файла не выполняет распознавание бренда по изображению.

## Определение продукта

`src/lib/brandIcons.ts` использует tldts/Public Suffix List, включая private suffixes. IP, локальные и некорректные адреса не отправляются в каталог как домены. Передаются только основной домен и поисковая строка, без пути и параметров URL. Название плитки и содержательная часть поддомена дают не более двух автоматических запросов. Технические метки поддомена отбрасываются.

Пользователь может заменить поисковый текст или ввести официальный домен продукта. Это не меняет адрес плитки. Иконки основного домена остаются доступны при изменении поиска. Из двух автоматических запросов выбирается максимум по одному бренду; при одном запросе — максимум два бренда. Совпадение названия показывается как предположение, без автоматического применения.

Небольшой реестр проверенных соответствий находится в `getKnownBrand`: DataLens → datalens.tech (официальный https://github.com/datalens-tech), GitLab → gitlab.com, JetBrains → jetbrains.com. Он позволяет запрашивать все источники для этих продуктов даже при недоступности поиска AnyLogo. Это помогает при неполном индексе поиска AnyLogo. Не добавляйте автоматически сконструированные домены. На проверке 13 ноября 2026 поиск `datalens` вернул пустой список, а Brand kit официального домена вернул PNG 48×48. Качество конкретного изображения зависит от источника. У mos.ru получен SVG. Наличие и качество выдачи могут меняться.

## Запросы и кэш

Фронтенд обращается только к локальным API. Оба сервера реализуют одинаковые контракты:

- `GET /api/brand-search?query=...` → `{ok, suggestions: [{name, domain}]}`.
- `GET /api/brand-kit?domain=...` → `{ok, variants: [{shape, width?, height?, scalable?}]}`.
- `GET /api/brand-image?provider=pubrio|debounce|anylogo&domain=...&variant=icon|wordmark` → `{ok, localIcon}`. Без provider используется AnyLogo для совместимости. Pubrio и DeBounce поддерживают один вариант icon; неподдерживаемый wordmark возвращает 400 без обращения в интернет.

Интернет-поиск запускается только в открытом picker, с задержкой ввода 500 мс. Встроенный поиск не имеет этой задержки. Закрытие окна/смена запроса отменяет применение старых результатов и последующие шаги; уже начатый общий запрос заканчивается в кэш. Одинаковые параллельные обращения объединяются. При переключении вкладок и повторном открытии повторно используются результаты.

Кэш сервера сохраняется на диск: положительный поиск — 24 часа, пустой — 15 минут; положительный kit — 7 дней, пустой kit — 1 час; сетевые ошибки — 30 секунд; отсутствие изображения — 1 час. Данные не обновляются в фоне. Метаданные ограничены 200 записями; Swift отдельно хранит до 500 соответствий источников файлам. В Vite общий лимит метаданных и соответствий — 200 записей.

Общий предел на процесс: три одновременных upstream-запроса и 60 скачиваний изображений за скользящую минуту. Дополнительно: AnyLogo — 15 запросов метаданных и 40 изображений в минуту, Pubrio и DeBounce — по 30 изображений в минуту. Это консервативные внутренние пределы Launey, а не обещанные лимиты провайдеров. Cooldown и Retry-After независимы для каждого источника и сохраняются на диск. Ошибка или 429 AnyLogo не останавливает Pubrio и DeBounce. Кэш доступен во время паузы. Автоматических повторов нет.

Для одного поиска рассматривается основной домен и максимум два домена продуктов. Pubrio и DeBounce начинают скачивание независимо от получения Brand kit AnyLogo. Быстрые результаты публикуются сразу; закрытие окна или изменение запроса подавляет поздние ответы и последующие шаги. Локальные каталоговые варианты и выбор пользователя не сбрасываются ответом медленного источника.

### Отдельные результаты без объединения

Идентификатор карточки — `provider:domain:variant`, а не хеш изображения. Одинаковые и похожие изображения разных источников всегда остаются отдельными карточками. Даже icon и wordmark одного источника не объединяются, если сервис вернул одинаковое содержимое. Выбор в интерфейсе привязан к идентификатору результата, чтобы одинаковое содержимое не подсвечивало несколько карточек.

Файлы имеют пути `/icon-cache/{provider}-{sha256}.{ext}`. Префикс источника сохраняет раздельность даже при одинаковых байтах. Внутри одного источника повторное использование уже сохранённого файла экономит место, но не объединяет карточки. Старые пути AnyLogo продолжают работать. Возраст метаданных не удаляет файлы: на них могут ссылаться плитки и экспорт. Сохранённые иконки и экспорт не требуют доступности провайдера.

### Проверка файлов и отсутствующих логотипов

Все провайдеры используют один ограниченный загрузчик: фиксированные HTTPS-хосты, проверка редиректов, таймаут 8 секунд, 512 КБ для JSON и 5 МБ для изображения. Формат определяется по содержимому; растр ограничен 4096×4096, SVG проверяется на активное содержимое и внешние ресурсы. Некоторые сложные допустимые SVG могут быть отклонены. Выбор становится доступен после успешного декодирования локального файла браузером. Swift дополнительно декодирует растры ImageIO.

HTTP 404 и явные признаки fallback в заголовках считаются отсутствием логотипа и кэшируются на час. Проверка 14 ноября 2026 выявила фиксированную заглушку Pubrio: SVG 40×40 с HTTP 200 без специального fallback-заголовка. Только точный отпечаток этого известного файла у Pubrio считается отсутствием логотипа. Он хранится в тестовой фикстуре; это не сравнение кандидатов и не дедупликация. Изменившиеся или неизвестные заглушки нельзя гарантированно определить автоматически. `Cache-Control: no-store` сам по себе не означает заглушку. DeBounce в проверке неизвестного домена вернул 404 и `x-logo-status: not-found`.

Корректный формат не гарантирует правильный бренд: проверка AnyLogo ранее обнаружила чужие изображения. Источник подписан на каждой карточке, автоматического применения нет.

## Проверки

Из `launey-web`:

```sh
npm ci
npm run test:icons
npx tsc -b
npx vite build
```

Из корня проекта (macOS):

```sh
swiftc macos/Launey/AnyLogoService.swift tests/anylogo-swift-checks.swift -o /tmp/launey-anylogo-checks
/tmp/launey-anylogo-checks
```

Node-тесты используют подставной fetch и временные каталоги; Swift-тесты — подставной transport. Они не расходуют квоты провайдеров. Проверяются нормализация домена, кэш после перезапуска, пустые ответы, single-flight, лимиты, независимые cooldown, раздельные карточки, постепенную выдачу, отмену устаревшего поиска, форматы и ограничения файлов. Для штатной сборки приложения нужен Xcode с принятой пользователем лицензией.

Документация AnyLogo: https://anylogo.dev/docs/search/, https://anylogo.dev/docs/kit/, https://anylogo.dev/docs/rate-limits/, https://anylogo.dev/terms/.


Документация Pubrio: https://docs.pubrio.com/en/api-reference/logo-api. Документация DeBounce: https://debounce.com/logo-api/.

## Контраст и тема

В карточках выбора и на плитках нейтральные одноцветные знаки с прозрачным фоном отображаются белыми на тёмной теме и чёрными на светлой. При заданном пользователем цвете фона иконки контраст выбирается по этому фону. Цветные знаки и градиенты не инвертируются. Преимущественно тёмные или светлые цветные надписи получают контрастную подложку при необходимости; непрозрачные изображения и чёрно-белые эмблемы сохраняют своё оформление.

Анализируются пиксели уже загруженного изображения в уменьшенном размере до 64×64. Новых сетевых запросов для анализа или смены темы нет. Результаты анализа хранятся в памяти (до 200 записей, без удержания больших data URL); недоступное для чтения изображение остаётся без преобразований. Оригинальный файл не переписывается, экспорт и импорт сохраняют исходные данные.

## Компактный выбор

«Логотипы» использует ту же сетку 64×64, что и App Store. На карточках нет названий, доменов, формата или размеров; служебные пояснения и подпись выбранного результата убраны. Название, вариант и источник доступны при наведении и через доступное имя кнопки. Выбранный вариант выделен рамкой и `aria-pressed`. Неудачные загрузки и ошибки отдельных источников не показываются пользователю. Во время поиска остаётся индикатор загрузки; после завершения поиска без доступных изображений выводится только общее сообщение «Логотипы не найдены». Результаты разных источников сохраняются отдельными карточками.
